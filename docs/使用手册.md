## 1. 密聊是什么

密聊是一个私人的端到端加密聊天网站，用法和 Telegram 类似。

- **只有聊天里的人能看到内容。** 消息、图片、文件、头像、群名都在你的浏览器里加密后才发出，服务器只保存看不懂的密文，管理员也读不到。
- **只对受邀的人开放。** 没有被放行的网络，连登录页都看不到。
- 不需要手机号，也不需要邮箱。

想了解具体怎么加密、服务器能看到什么，请看[安全设计](安全设计.md)。

## 2. 注册与登录

### 注册

1. 打开管理员发给你的邀请链接，或者在「访问验证」页输入邀请码。
2. 设置用户名、昵称和密码。
3. 抄下系统给出的 **24 个恢复词**，然后按提示核对其中 3 个。

> **恢复词非常重要。** 忘记密码时，只有它能找回账号和聊天密钥。请写在纸上或存进密码管理器，不要截图发给别人。

### 登录

- 在新设备上输入用户名和密码登录。开启了两步验证的，还要再确认一次（见[第 9 节](#9-账号安全)）。
- 也可以用已经登录的设备扫码登录：在新设备上选「用已登录的设备扫码」，再在旧设备上打开「设置 → 设备 → 扫码登录新设备」。
- 忘记密码时，在登录页选「忘记密码？用恢复词找回」。找回后，所有旧设备都会被退出登录。

### 访问验证

如果你换了网络（比如从家里换到公司），可能会先看到「访问验证」页。输入访问密码就能放行这个网络。访问密码可以向管理员要。

## 3. 聊天

| 想做什么 | 怎么做 |
|---|---|
| 发起私聊 | 左上角 ☰ →「新建私聊」，输入对方的完整用户名；或者打开对方的名片链接 |
| 回复 | 右键（手机上点一下）消息 →「回复」；手机上把消息向右滑也可以 |
| 编辑 / 删除 | 右键自己的消息。删除时可以只删自己这边，也可以为双方删除 |
| 转发 | 右键 →「转发」。多选消息后转发，可以合并成一条「聊天记录」 |
| 表情回应 | 右键消息，点上方的表情 |
| 置顶消息 | 右键 →「置顶」，置顶的消息显示在聊天顶部 |
| 收藏 | 右键 →「收藏」。收藏夹在左上角 ☰ 里，原消息被删除后收藏仍然保留 |
| 投票 | 输入框旁边的图表按钮 |
| 定时发送 | 输入框旁边的日历按钮 |
| 贴纸 | 输入框旁边的贴纸按钮。右键图片可以「添加到贴纸」 |
| 语音消息 | 按住麦克风按钮说话 |
| 阅后即焚 | 聊天信息 →「阅后即焚」，选择多久后自动删除 |
| 单条限时消息 | 输入框旁边的沙漏按钮，选 1 分钟到 7 天。只对接下来发的**这一条**消息有效，到时间后双方都会删除 |
| 搜索所有聊天 | 左上角的搜索框，能搜聊天名和聊过的内容。内容搜索只在这台设备上进行 |
| 在当前聊天里搜索 | 点聊天顶部的放大镜，或按 Ctrl/⌘ + F。可以按发送者、日期筛选；用 ↑ ↓ 或回车在结果之间跳转。默认只搜本机已有的消息，点「搜索全部历史」会读取这个聊天的全部消息 |
| 格式 | `**粗体**` `*斜体*` `~~删除线~~` `` `代码` `` `\|\|剧透\|\|`；在群里输入 @ 可以提到某人 |

**快捷键：**

| 按键 | 作用 |
|---|---|
| Ctrl/⌘ + K | 搜索所有聊天 |
| Ctrl/⌘ + F | 在当前聊天里搜索 |
| Ctrl/⌘ + Shift + N | 新建私聊 |
| Ctrl/⌘ + , | 打开设置 |
| Alt + ↑ / ↓ | 切换到上一个 / 下一个聊天 |

**断网时：** 仍然能看已经缓存的聊天。这时写的文字消息会先加密保存在本机，联网后自动发出。

### 私密对话

需要更高保密性时，在对方的信息页选「发起私密对话」。

- **只在两台设备上**：你发起的这台设备，和对方第一台上线接受的设备。你们的其他设备上看不到它。
- **前向保密**：每条消息用一次性密钥加密，用完即删。以后就算设备被入侵，已经删除的消息也解不开。
- **不保存在服务器上**：文字消息送达后服务器立即删除；图片和文件（加密的）在服务器上最多保留 14 天。
- **阅后即焚**：默认 1 天，可以在私密对话信息里改成 30 秒到 1 周，或者关闭。
- **不能转发、不能导出**，也不进本机搜索。
- **安全码**：在私密对话信息里，和对方比对一致即可。
- **结束**：私密对话信息 →「结束私密对话」，双方设备上的这个对话都会被删除。
- **注意**：换设备、清除浏览器数据、退出登录后，私密对话就没有了，无法恢复。
- 如果对方的安全码变了，要先在对方信息页核对安全码，才能再发起或接受私密对话。
- **私密通话**（v0.9）：私密对话顶部有电话和摄像头按钮。只会在绑定的那两台设备上响铃，通话记录只留在这两台设备上。
- **标记为已验证**（v0.9）：比对过安全码后，在私密对话信息里打开「已核对，标记为已验证」，标题旁会显示对勾。
- **置顶、免打扰**（v0.9）：在私密对话信息里设置，只对这台设备生效。
- **对方换了设备**（v0.9）：如果对方那台设备已经不在了（退出登录、清除了数据或换了设备），打开对话时会提示，可以一键重新发起。

## 4. 聊天列表整理

在聊天上右键（手机上长按）可以：

- **置顶**：最多 5 个。
- **免打扰**：可选 1 小时、8 小时、1 天、7 天或一直。免打扰期间不弹通知，未读数显示为灰色。
  - 但有人 @你 时仍然会通知。不想要的话，在「设置 → 通知与存储」里关掉「免打扰的聊天里有人 @我 时仍然通知」。
  - 这项只在网页打开时有效，只对当前设备生效。
- **归档**：把聊天收进列表顶部的「归档聊天」。有新消息时会自动移出（免打扰的聊天除外）。
- **标记为未读 / 已读**。
- **添加到分组**：列表上方的标签可以切换「全部 / 未读 / 私聊 / 群组」和你自己建的分组。在标签上右键可以「全部标为已读」。

这些设置会加密同步到你的所有设备，服务器看不到。

## 5. 群组

- **建群**：☰ →「新建群组」。群最多 100 人（v0.9 起，之前是 50 人）。
- **邀请**：在群信息里点「邀请链接」生成链接或二维码。新成员只能看到加入之后的消息。
- **管理员功能**：
  - 改群名、群头像、群公告；
  - 设置「仅管理员可发言」；
  - 禁言成员；
  - 设置阅后即焚。
- 群名、群头像、群公告都有管理员签名，服务器改不了。如果被篡改，会出现红色警告。
- 如果看到红色的「成员列表与签名记录不一致」，说明服务器给出的成员名单可能被动过手脚。这时应用会停止发送消息，请联系群管理员核实。

## 6. 语音与视频通话

- **一对一通话**：点私聊顶部的电话或摄像头按钮。
  - 视频通话中可以共享屏幕，手机上可以切换前后摄像头。
  - 网络切换（Wi-Fi 和流量之间）时会自动重连，右上角的三格信号表示网络好坏。
- **群通话**：点群聊顶部的电话或摄像头按钮发起。
  - 其他人会看到「群通话进行中」横条，点「加入」就能进来。
  - 人数上限：语音 8 人，视频 6 人。
  - 通话中点显示器按钮可以共享屏幕，语音通话也可以。
  - 通话结束后，聊天里会留下一条「群语音通话 · N 人 · 时长」的记录，点它可以再发起一次。
- 所有通话都是端到端加密的。在「设置 → 外观与快捷键」里打开「通话时隐藏我的 IP」，对方就看不到你的 IP 地址。

## 7. 图片、文件和共享内容

- **发送**：可以拖进聊天窗口、粘贴，或者点回形针按钮选择文件。
- **大小**：单个文件最大 2 GB（上限由管理员设置）。
- **照片**：默认会去掉拍摄位置等隐藏信息；想保留原样，选「按原文件发送」。
- **大文件上传中断**：网络断了会自动续传。如果是刷新或关闭了页面，重新打开那个聊天会看到「上传中断」提示，点「选择同一文件继续」，已经传过的部分不会重传。
  - 在电脑版 Chrome、Edge 上（v0.9 起），用回形针按钮或拖进来的文件，提示里会直接显示「继续上传」，不用再选一次文件（浏览器可能会问一次是否允许读取这个文件）。
- **共享内容**：聊天信息 →「共享内容」，按「图片和视频 / 文件 / 语音 / 链接」分类查看这个聊天里发过的东西。链接需要在本机解密后才能查找，可以点「读取全部消息来查找」。
- **导出聊天记录**：聊天信息 →「导出聊天记录」。
  - 可以导出成网页（HTML），直接用浏览器打开；
  - 也可以导出成用口令加密的存档，以后在「设置 → 通知与存储 → 打开存档」里查看。

## 8. 联系人、头像与隐私

- **头像**：在「设置 → 个人资料」里点头像就能更换。
  - 头像也是加密的，只有和你在同一个聊天里的人能看到。
  - 群头像在群信息里由管理员更换。
- **备注名**：在对方的信息页点「添加备注名和备注」，只有你自己看得到。
- **核对安全码**：在对方的信息页点「查看安全码」。当面扫对方的二维码或逐位比对，一致后会显示「已验证」。如果对方的密钥以后变了，这个标记会自动消失，并提醒你重新核对。
- **屏蔽**：被屏蔽的人不能再给你发消息、打电话，也看不到你是否在线。
- **设置 → 隐私**：
  - 可以隐藏自己的在线状态、关闭已读回执；
  - 这两项是双向的：你隐藏了自己的，也就看不到别人的。
  - **模糊显示我的在线状态**（v0.9）：别人仍能看到你在线，但上线、下线都会随机延迟几分钟到半小时显示，看不出你准确什么时候在用。注意「正在输入」和已读回执仍然是实时的。
  - **推送通知延迟合并**（v0.9）：网页关着时，推送会延迟 2–8 分钟，期间的新消息合并成一条通知。
- **隐私屏**：页面切到后台时自动模糊，在应用切换界面里看不到聊天内容。

## 9. 账号安全

在「设置 → 安全」里：

- **两步验证**：开启后，在新设备登录时除了密码，还要再确认一次。可以用以下任意一种：
  - **通行密钥**（推荐）：用指纹、面容、电脑 PIN 或安全密钥确认；
  - **验证器 App**：Google Authenticator、Microsoft Authenticator、1Password 等 App 里的 6 位数字。

  开启时会给你 10 个备用恢复码。手机丢了的时候，每个恢复码可以代替验证码用一次。开启第一种验证方式时，需要再输入一次登录密码。
- **本机应用锁**：打开网页或闲置一段时间后，要输入 PIN 才能使用。
- **设备管理**：在「设备」页可以看到所有已登录的设备，并远程退出。新设备登录时，你的其他设备会收到提醒；如果不是你本人，点「不是我，让它下线」。
- **修改密码、重新生成恢复词**：都需要先输入当前密码。
- **网页代码指纹**：在「设置 → 安全」最下面。把它和更新说明里写的指纹比对，一致说明你运行的是发布的代码。v0.9 起，下面还会显示「已由发布密钥签名」。如果代码在版本号没变的情况下变了，页面顶部会出现提醒，请告诉管理员。

## 10. 多设备与备份

- **多设备**：同一个账号可以在多台设备上登录，聊天记录、收藏、贴纸、备注、置顶、分组都会同步。
- **会同步的设置**：聊天背景、通知预览、链接预览、隐私屏、通话中转、本机缓存。
- **只对当前设备生效的设置**：语言、字体大小、回车键。
- **个人数据备份**：在「设置 → 安全 →『导出个人数据』」里导出一个用口令加密的文件。
  - 里面有：备注名、收藏、贴纸、聊天分组、设置、屏蔽名单。
  - 以后可以在同一个账号，或者一个新账号里「导入个人数据」。导入只会添加，不会覆盖你现有的内容。
  - 聊天消息不在里面：消息本来就保存在服务器上；单个聊天可以用「导出聊天记录」另外保存。

## 11. 注销账号

「设置 → 安全 → 注销账号…」

- **注销前的确认**：要输入你的用户名和登录密码；开启了两步验证的，还要再确认一次。
- **会被删除的**：
  - 登录密码和恢复词；
  - 所有设备上的登录；
  - 两步验证；
  - 收藏、贴纸、备注、设置和头像。
- **自动退出**：你会退出所有群组。
- **会保留的**：你已经发出的消息。别人仍然看得到，发送者显示为「已注销账号」。
- **无法恢复**：注销后不能恢复，同一个用户名也不能再注册。建议先「导出个人数据」。
- 如果你是唯一的管理员，要先把另一位用户设为管理员才能注销。

## 12. 常见问题

**换了手机或电脑，聊天记录还在吗？**
在。登录后，历史消息会从服务器下载，再在本机解密。

**忘记了密码，也丢了恢复词怎么办？**
没有办法找回。这是端到端加密的代价：除了你自己，没有人（包括管理员）能解开你的密钥。

**为什么有时要重新输入访问密码？**
你换了网络，新的 IP 还没有被放行。

**通知里为什么看不到消息内容？**
推送服务商（Google、Apple 等）只会知道「有新消息」。网页开着时显示多少内容，可以在「设置 → 通知与存储」里调整。

**「发送匿名错误报告」会发送什么？**
页面出错时，只发送错误信息和出错的代码位置，帮助管理员修复问题。发送前会去掉引号里的文字和网址参数；不包含聊天内容，不带账号，服务器也不记录 IP。不想发送的话，在「设置 → 通知与存储」里关掉。

**看到红色的警告怎么办？**
可能是对方换了设备（安全码变更），也可能是服务器的数据不对。先按提示核对安全码，或者联系管理员，不要急着继续发消息。
